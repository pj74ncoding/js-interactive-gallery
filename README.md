## Installation

### Clone the Repository

```bash
git clone https://github.com/pj74ncoding/js-interactive-gallery.git
cd js-interactive-gallery



```

### Install Dependencies

Frontend:

```bash
cd js-interactive-gallery



npm install
```

### Run Development Servers

Frontend:

```bash
npm start
```
